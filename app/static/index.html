What ties these together

None of the five is a new data source. All five are the same table read five ways — one row per case, joined to site, scanner, model version and stratum. Finding 03 needs release identity beside clinical outcome. Finding 04 needs detector generation resolved at scan time. Finding 05 needs patient covariates beside correction impact. Those live in four different systems today, which is why none of these questions can currently be asked.

Why one portal, not five tools

Deployment is the cheap part. The expensive parts are integration — access to each source system, security review, data agreements, the PHI boundary — and learning — people changing how they work, and trusting a number enough to act on it.

Integration cost is paid once per source system. Learning cost is paid once per tool. So the economics say: pay the integration once, then add features as lenses rather than as products. Five separate tools would mean five security reviews, five logins, five training sessions, and five teams each quoting a slightly different version of the same metric.
